MinIO client (mc)

export AWS_REGION={{.Region}}
mc alias set s3 {{.S3URL}} {{.KeyAccess}} {{.KeySecret}} --api S3v4 --path on
mc ls s3/{{$eg}}/

mc takes its region from AWS_REGION, which hosts in a cloud often have set to their own. With another region, mc ls fails, and mc mirror copies nothing and still exits 0: check with mc diff.

Write only ({{at .Grants "writeonly"}}): the key can upload but not list or read, and many tools look before they write.

  • rclone: no_head = true and rclone copy --no-check-dest (or --no-traverse), to the bucket or a path in it ending in / (s3:{{$eg}}/incoming/: without the /, rclone looks the path up as a file, which the key can't, and stops). Not sync, and not copy without those flags: it uploads, then fails to check and uploads again.
  • mc: mc cp works; mc mirror doesn't.
  • AWS CLI: aws s3 cp works; aws s3 sync doesn't.
{{end}} {{if $co}}

Add only ({{at .Grants "createonly"}}): every upload must ask not to overwrite (If-None-Match: *) and be a single upload, not multipart.

  • AWS CLI: aws s3 cp --no-overwrite, which skips files that exist. For files over 8 MB, first aws configure set default.s3.multipart_threshold 5GB. aws s3 sync doesn't work.
  • mc: mc cp -H "If-None-Match:*" --disable-multipart.
  • rclone can't send If-None-Match, so it can't upload with this key.
  • Don't use mc mirror: it reports success even when every upload is refused.
{{end}}
